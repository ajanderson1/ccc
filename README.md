# ccc (Claude Code Cost)

> **This project has been deprecated and is no longer maintained.**
>
> It has been merged into **[claude-tui-tools](https://github.com/ajanderson1/claude-tui-tools)** as the `claude-tui-usage` package.

## Migration

```bash
pip install git+https://github.com/ajanderson1/claude-tui-tools.git#subdirectory=packages/usage
```

The new command is `claude-tui-usage` (replaces `ccc` / `cc_usage.sh`). The tool has been rewritten as a proper Python package with the same pace-aware monitoring features.
